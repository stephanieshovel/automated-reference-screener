# automated-reference-screener
An automated candidate reference check and compliance verification engine featuring an optimized CI/CD delivery pipeline. Built with FastAPI and Python.
### Operational Impact
* **Time-to-Hire Reduction:** Accelerates reference turnaround times from **3-5 business days down to under 24 hours**.
* **Zero Manual Follow-Ups:** Eliminates manual coordinator emails by introducing programmatic outreach loops.
* **Compliance & Security:** Implements basic digital fingerprint cross-checking to automatically isolate fraudulent references.
